### Test Framework ###

# It replaces `jest` / `mocha` from the JS baseline (AAP §0.6.3). The
# accompanying plugins cover async tests (`pytest-asyncio`), coverage
# (`pytest-cov` driving the `coverage` engine), mock fixtures
# (`pytest-mock`), and parallel execution (`pytest-xdist`) — together they
# replace `jest --coverage`, `jest.mock`, `jest --maxWorkers`, and `sinon`
# from the JS ecosystem (AAP §0.6.3 substitution rows).
#
# Versions follow AAP §0.6.3 minor lines pinned to the highest stable
# patch at refactor planning time.
#
# Known finding (acceptable per AAP §0.8.5 / agent-prompt Phase 12 which
# require *zero high-severity* findings):
#   * CVE-2025-71176 (GHSA-6w46-j5rx-g56g) — pytest <= 9.0.2 on UNIX uses
#     predictable /tmp/pytest-of-{user} directories enabling local DoS /
#     priv-esc via symlink races. Severity: **Moderate (CVSS 6.8 / MEDIUM,
#     local attack vector, low impact)** per the GitHub Advisory and NVD.

#     remain satisfied. The AAP §0.7.1 defect-detection pipeline also
#     remains valid — pytest still drives test parity and runs cleanly on
#     CPython 3.13. Re-evaluate when the pytest 8.3 line ships a backport

### Linters and Formatters ###
# `ruff` is the primary Python linter — AAP §0.4.1 selects it because it is
# 10–100× faster than `pylint` and consolidates `flake8`, `isort`, and parts
# of `pylint` / `black` into a single binary, replacing `eslint` from the JS
# baseline. `black` is the opinionated formatter (replaces `prettier`).
# `isort` orders imports (replaces `eslint-plugin-import` sort rules).
# `pylint` is retained as a deeper / second-pass linter per AAP §0.7.1
# defect-detection pipeline ("ruff check, pylint, mypy --strict, bandit").
#
# `black` is pinned to 26.3.1 (the first release that fixes the CVE) to
# remediate CVE-2026-32274 / GHSA-3936-cmfr-pm3m — a **HIGH severity**
# (CVSS 4.0 base score 8.7) path-traversal / arbitrary-file-write
# vulnerability in the cache-key construction (the unsanitized
# `--python-cell-magics` value is incorporated into the cache filename
# when its concatenated string stays under the 32-character hash
# threshold). Affected versions: < 26.3.1 (i.e., the AAP-listed
# 24.10.0 is vulnerable). Without this bump, AAP §0.8.5 validation
# criterion "`pip-audit` reports zero high-severity vulnerabilities"
# fails. This proactive bump satisfies the AAP §0.7.1
# defect-remediation pipeline ("iterate until zero high-severity
# findings") and mirrors the precedent in `requirements.txt` where
# `python-dotenv` and `torch` were bumped beyond their AAP-listed minor
# lines for the same reason. 26.3.1 ships as a pure-Python wheel for
# Python 3.13 and remains a drop-in replacement for 24.10.0 at the
# command-line interface, satisfying the agent-prompt Phase 10 discipline
# ("MUST select the highest stable patch within each minor version listed
# in AAP §0.6.3") under the documented CVE-remediation exception.
pylint==3.3.3
ruff==0.8.4
black==26.3.1
isort==5.13.2

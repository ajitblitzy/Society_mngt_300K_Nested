## Uniform Contract

Every function in this module identity shares the signature `mod_3_M(x) → number`. It accumulates `x*1 + x*2 + x*3` (that is, `6*x`) and adds `10` when the running total is even, so for integer `x` the result is `6*x + 10`.

The canonical body, the arithmetic, and the worked values are documented once in [Code Conventions & Uniform Contract](../../architecture/code-conventions.md) and are not repeated here.
